# 需求分析文档文件夹说明

本文件夹保存“个人 Markdown 笔记与知识管理工具”课程项目的四份主要Markdown材料，并附两张来源证据图片。本次提交以本目录内的01文件V1.1批改补正版为准。

## 文件说明

### 1. `01-需求分析文档.md`

正式的软件需求规格说明书（SRS）草案，包含：

- 项目背景与问题描述
- 项目目标、用户分析和典型使用场景
- P0、P1、P2 功能需求
- 性能、易用性、可靠性、安全和可维护性需求
- 数据实体与生命周期
- 系统边界、技术约束和资源约束
- 可执行的验收标准和风险分析
- 需求来源、追踪关系和人工核实状态

文档中的 `FR-*`、`NFR-*` 和 `BR-*` 是需求编号，`AC-*` 是验收用例编号。标记为“待确认”或“待测试”的内容不表示已经得到用户确认或已经通过测试。

### 2. `02-AI协作记录.md`

记录需求分析过程中的：

- 用户提示词和任务目标
- 选题比较与需求文档生成过程
- 一致性审查与修订过程
- 采纳、修改、否决的内容及理由
- 当前仍待确认的产品决策

该文件用于满足课程对 AI 协作过程记录的要求，不替代需求文档中的正式需求。

### 3. `03-人工核实说明.md`

说明关键结论如何核实，以及当前属于“已由材料确认”“待人工确认”“待测试”还是“范围外”的内容。文件还提供了后续访谈、故障演练、性能测试和教师评审的记录模板。

### 4. `README.md`

说明本文件夹的用途、文件分工、编号规则和当前文档状态，便于提交或交接时阅读。

## 阅读顺序

建议先阅读 `README.md`，再阅读 `01-需求分析文档.md`；如果需要了解文档形成过程，阅读 `02-AI协作记录.md`；如果需要查看哪些结论已经核实，阅读 `03-人工核实说明.md`。
