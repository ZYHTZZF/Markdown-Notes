## 目录说明

“需求基线”同时保留实验一原AI协作记录、人工核实说明、旧README和两张证据图片，供读者核对SRS中的相对链接。它们是历史来源附件，不是本实验新编的协作／测试记录；旧README描述的是实验一，实验二以本文件为准。旧ZIP不会嵌套在本包中。

“设计图”保存4张PNG：系统架构、保存时序、备份恢复流程、核心数据关系。它们由主文档中的Mermaid源图渲染生成，可直接打开查看，便于不支持Mermaid的阅读器使用。

V1.1评审修订入口：1.2为组件—模块编号及复杂度取舍，1.5为集中术语表，4.1／5.4为编号规则，7.1.1为OP运行预算，10.4为条件性／未执行验证门禁，11.3.1为TD-20具体测试步骤。第03文件第5节记录修改前后及影响。

## 文档状态与提交

版本：SDD V1.1（设计评审修订版），2026-10-12。沿用27条功能需求、33条非功能需求、15条业务规则和28个原AC编号；新增3项运行设计预算和TD-20验证计划。软件尚未开发，测试为计划，性能为目标；P2不作为基础版已实现功能，格式升级测试在存在真实迁移实现后执行。新增阈值为设计拟定，默认产品口径仍待负责人评审，不伪造已批准记录。

文档采用UTF-8 Markdown，图使用Mermaid并随附静态PNG，另有文字和表格解释。已检查需求编号覆盖、文档相对链接、表格列数、基线副本摘要及图表渲染；这些是文档质量检查，不是软件功能测试。没有将Markdown图表语法作为应用代码交付。

同级目录的“软件设计文档_实验二.zip”为本次提交包，包含本目录内容；不含旧提交ZIP或开发依赖。任务截图要求单个上传文件不超过5 MB，打包时检查实际ZIP大小。提交前个人可核对默认口径，任何功能或指标修改需同步更新追踪与变更记录。
