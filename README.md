# 知页 · Markdown Notes

面向学生与知识工作者的本地个人 Markdown 笔记与知识管理工具，Windows 桌面版 1.5.1。采用 Electron、React、TypeScript 与 SQLite。

## 功能

- Markdown 编辑、安全预览、自动保存与回收站。
- 数学公式离线渲染、单篇PDF导出，嵌入中文与公式字体。
- 自定义主色与本地背景、背景强度、PDF带背景／纯白导出。
- 可选即时编辑：输入 `## ` 立即呈现二级标题，保留Markdown源码及原分屏模式。
- 标签管理、全文搜索、匹配高亮和分页。
- `[[笔记名称]]` 双向引用、自引用、反向链接与原子重命名联动。
- 单篇／批量导出、完整备份、正常恢复与主数据损坏后的故障恢复。
- 业务数据与索引分离、索引重建和容量校验。

基础版不包含云同步、移动端、多人协作；插件与主题按原文档作为 P2 后置。

## 从源码运行

Windows 开发环境需要 Node.js 24 与 npm。首次安装依赖需要网络，构建后的桌面成品可离线使用。

```powershell
cd markdown-notes
npm ci
node node_modules/electron/install.js
npm run build
npm start
```

执行 `npm run package` 后，可直接运行 `markdown-notes/release/知页-win-x64/知页.exe`。请保留整个成品目录。依赖、构建产物、个人资料库及 ZIP 交付包不纳入 Git 版本控制。
