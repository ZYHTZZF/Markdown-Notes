# 知页1.4.0：即时编辑模式

日期：2026-10-20。来源为用户本轮追加要求：希望保留现有左源码／右预览，并增加类似Typora、飞书文档的可选模式，输入两个 `#` 接空格就呈现二级标题。以下为本轮实现，不回填为原课程需求已确认的内容。

## 使用方法

笔记工具栏有“写作、即时、分屏、阅读”四个入口。新用户继续默认分屏；选择“即时”后，在一个区域内直接编辑，格式随输入呈现。编辑字号、主色、背景与现有设置共用。

- `# `—`###### `：一至六级标题，`## ` 后即可直接输入二级标题文字，前缀隐藏，标题文字可直接修改。
- `- `、`1. `：无序／有序列表，Enter继续条目；空条目按Enter退出，具体缩进沿用Markdown规则。
- `> `：引用；`**文字**`、`*文字*`、`~~文字~~`、行内反引号：粗体、斜体、删除线、行内代码。
- 双向引用隐藏方括号并显示为关联文字；Ctrl+单击打开笔记。普通HTTP(S)链接也需Ctrl+单击打开，普通单击用于编辑。
- 公式、表格和分隔线平时显示渲染结果，点击后在原位置显示对应源码；移开光标后恢复呈现。块级语法按原Markdown规则输入，不增加图形表格编辑器。
- 工具栏格式按钮可用于当前位置／选中文字。Ctrl+Z撤销，Ctrl+Y重做，Ctrl+S保存；Ctrl+N新建、Ctrl+K搜索继续生效。

围栏代码保留文本与围栏，采用代码样式；图片仍按基础版规则不加载。暂未专门呈现的Markdown结构保留源码，不转成任意HTML。即时模式提供常用语法的同区呈现，不宣称包含Typora或飞书的全部富文本功能。需要精确处理链接目标、复杂嵌套或不受支持的排版时可切回写作／分屏模式。

## 原文、保存和记忆

使用CodeMirror的文本状态与显示装饰：数据库中始终是Markdown文本，没有另存HTML，也不对全文执行富文本反向序列化。切换模式本身不改正文、不增加正文修订号；外部重命名／恢复带来的内容更新不会作为用户输入再次保存。新编辑继续走原自动保存、修订号、容量与关闭前保存流程，回收站即时编辑器为只读。

原文中的公式、引用与代码保持原样；统一CRLF换行的文档在本模式编辑后保持CRLF。混合换行的非常规文本在编辑时按该编辑器选择的换行类型输出，未将混合换行保真作为验收结论。撤销历史仅属于当前即时编辑器会话，切换模式或笔记后不承诺跨会话历史。

即时模式的开关保存在本机界面存储；另外三种模式继续使用原业务偏好。完整备份格式与业务schema不变，备份恢复到另一台设备后不会自动打开即时模式；这避免向旧版严格的偏好枚举写入新值导致备份不兼容。

## 安全与实现定位

即时编辑器按需从本地资源加载，不依赖网络。源码通过文本节点编辑；公式／表格采用现有安全Markdown、DOMPurify与KaTeX管线，原始HTML不执行、外部图片不加载。新模式不增加文件读取或业务IPC权限。

| 位置 | 职责 |
|---|---|
| `renderer/live-editor.tsx` | 文本状态、Markdown装饰、块预览、编辑命令与原文同步 |
| `renderer/live-editor.css` | 标题、列表、行内格式、代码、块预览及小窗口适配 |
| `renderer/main.tsx` | 第四种模式、按需加载、工具栏与本机记忆、保存流程接入 |
| `tests/e2e/live-editor.spec.ts` | 实际输入、原文往返、公式／表格、重启、只读与安全验证 |

## 实际验证与限制

新增三项真实桌面测试覆盖：`## `即时变为可编辑二级标题、列表续写、粗体与工具栏、隐藏结束标记处换行、撤销／重做、源码往返；原文无编辑时修订号不变、CRLF、公式／表格、模拟组合事件配合中文插入、关闭前保存及重启记忆；1080×700布局、原文插入、安全与回收站只读。原核心、外观、数学公式／PDF、分栏、备份恢复及退出检查同时回归，成品EXE另执行标题转换与保存。

组合输入测试使用浏览器事件与文字插入，不替代真实Windows输入法的全量人工检查；未宣称所有输入法、无障碍工具、复杂嵌套或1 MiB极端语料已穷尽验证。即时模式仍有独立约503 kB的压缩前JS分块，构建器保留大小提示；按需加载使默认分屏不必立即加载该分块，未把历史1.0.0性能记录冒充本模式性能。

开发中真实发现隐藏粗体结束标记处按Enter会将换行插入结束标记前，已修正命令顺序，在保存Markdown前保留正确闭合；桌面回归包含该情况。编辑器内部存在无src的光标辅助IMG，安全断言针对携带src的图片，不能将内部辅助节点当作远程图片加载；回收站只读断言定位内容区域，避免与块预览的不可编辑节点混淆。
