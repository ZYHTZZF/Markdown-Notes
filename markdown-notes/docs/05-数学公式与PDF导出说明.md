# 知页1.2.0：数学公式与PDF导出

执行日期：2026-10-20。来源为用户在现有开发对话中的原文追加要求：“还有我希望能够支持markdown中常见的数学公式输入格式，不要出现乱码，以及我需要能够导出pdf，pdf也不要出现乱码”。以下为本轮实现约定，不倒写为原课程SRS／SDD已经包含的功能。

## 1. 输入与显示

| 形式 | 输入示例 | 约定 |
|---|---|---|
| 行内 | `$E=mc^2$`、`\(a_1+b_2\)` | 单行，随段落显示 |
| 独立公式 | `$$\frac{a}{b}$$`、`\[\sqrt{x}\]` | 居中显示；多行时定界符单独占行 |
| 矩阵、分段、对齐 | `pmatrix`、`bmatrix`、`cases`、`aligned` | 放在独立公式内，使用标准LaTeX环境语法 |
| 中文 | `\text{中文说明}` | Windows中文系统字体回退，随PDF嵌入 |
| 字面标记 | 行内／围栏／缩进代码中的公式标记、`\$` | 不解释为公式 |

使用KaTeX0.19.0的支持集，不等价于完整LaTeX编译器；不运行任意命令、不加载远程包、图片或字体。为避免金额误判，单美元定界符内侧不留空白，结束美元后不能紧接数字或美元；普通金额建议转义为 `\$`。完整公式内的 `[[名称]]` 不创建笔记引用，也不受重命名联动影响。

未闭合定界符保留普通文本；已闭合但语法错误或不支持的命令显示源码提示。单公式最多16,384个UTF-16码元，超长输入按普通文本处理；宏展开最多1,000次，用户指定尺寸最多20em，宏不在公式之间共享。上述均为实现保护值，不声称经过满容量公式性能认证。

## 2. PDF行为与数据保护

笔记右上角新增“导出PDF”，保留原Markdown导出。当前支持单篇有效笔记，不增加批量PDF、打印机设置、论文模板或可恢复PDF。点击后先完成普通保存，再获取这篇笔记的只读快照；原生另存为对话框期间的后续修改不会自动混入本次快照。取消不改文件；恢复期间或资料库代发生变化时拒绝本次导出。

输出A4，四边留白，内容为笔记标题及渲染正文，保留基本标题、列表、代码、表格和公式。PDF嵌入实际使用的中文与KaTeX字体，文字可选择；不包含标签、引用索引、回收站和备份元数据。笔记内部引用仅保留可读文字，不提供PDF跨笔记导航。PDF不能用于完整恢复。

独立公式尽量避免跨页，超宽公式按页宽缩小；很长公式建议用 `aligned` 分行，超高单公式仍需拆分。预览允许公式区域水平滚动。公式与普通正文使用同一Markdown／KaTeX／DOMPurify管线，字体及CSS全部位于本地打包资源，打印前等待字体就绪。

输出先写同目录随机临时文件并同步，再重命名发布。打印或写入失败保留原目标文件并清理临时文件；禁止写入内部资料目录，含解析后的父目录路径检查。打印窗口隐藏、沙盒运行，只能读取属于本任务的快照，不能调用业务桥；任务结束或主窗口关闭时销毁。渲染和字体准备60秒超时则报错，不把未完成排版发布为成功。

## 3. 旧资料兼容

Markdown原文、业务schema版本和完整备份格式仍为1。新增数学语法不重写正文、标题、时间或笔记修订号。因“公式内不产生引用”与旧解析不同，首次可写打开旧库时在事务内重建派生 `note_refs`，以SQLite `user_version=1` 标记本地解析规则版本，并追加覆盖全部笔记的变更清单，使已有搜索／引用索引追平；失败回滚。这个标记不是新业务schema，也不是AC-26的业务格式迁移。

新语法可能使旧笔记中的成对美元文字显示为公式；可转义美元或放入代码。启动时旧目录升级的满容量耗时未单独测量，1.0.0历史性能记录不能直接当作本轮公式性能。

## 4. 实际验证与证据

- 五项新增核心测试：四种定界符、金额／转义／未完成输入、公式内引用与重命名排除、分式／积分／矩阵／对齐／中文／代码、错误与危险命令及宏边界、旧目录升级幂等与原文保护；部分要点在同一测试内组合验证。
- 两项新增桌面测试：真实离线字体加载、预览根号SVG保留、46个公式与六页导出、先保存再导出、取消、内部路径拒绝、注入打印失败后旧文件保留及重试、隐藏窗口清理。
- 完整回归：32项核心、10项桌面、10轮退出检查通过，打包EXE另执行公式预览与真实PDF导出。

实现依据：[KaTeX选项与安全限制](https://katex.org/docs/options.html)、[Electron printToPDF](https://www.electronjs.org/docs/latest/api/web-contents#contentsprinttopdfoptions)。
