# 1.1.1 三栏宽度调整与收起

导航、笔记列表与编辑区之间现在有两条可拖动的分隔条，悬停或聚焦时显示蓝色提示。拖动左侧分隔条改变导航宽度，拖动中间分隔条改变列表宽度，编辑区自动占据剩余空间。

- 双击分隔条或聚焦后按Enter，恢复该栏的默认宽度。
- 到达最小宽度后继续向左拖动48px，分隔条显示“松开隐藏”提示；松开后收起该栏。仅到最小宽度而未继续拖动，不会意外隐藏；取消拖动不执行收起。
- 顶栏搜索框左侧的两个按钮分别控制导航和笔记列表，可随时隐藏或展开。重新展开时恢复收起前的宽度，空间不足则按约束收紧；两个区域可以同时收起。
- 隐藏状态也在本机记忆。输入搜索、切换全部笔记／回收站或选择标签时会自动展开列表，以便看到结果。
- Tab可聚焦分隔条；左右方向键微调10px，Shift＋方向键调整50px；Home／End移动到当前允许的最窄／最宽位置。
- 导航范围176—320px，列表范围220—480px，同时至少给编辑区保留560px。实际最大值会根据窗口和另一栏的宽度收紧。
- 宽窗口默认导航200px、列表260px；1080—1250px窗口默认176px、232px。
- 拖动结束时记忆本机宽度。窗口变小时临时收紧显示宽度，扩大窗口后恢复已选择的宽度；不会把自动收紧值覆盖为新的用户选择。
- 宽度记录存放于本机界面存储，不新增业务数据库、IPC或备份字段。跨设备完整恢复仍沿用既有可移植偏好范围。

拖动使用指针捕获及窗口级移动／释放监听，按松开位置完成最后一次调整；取消、失去焦点及窗口尺寸变化均结束拖动，避免光标或禁止选中文字的状态残留。只调整布局变量，不替换编辑器、笔记内容或当前编辑会话。

验收场景包括1480与1080宽度下的拖动、最小／最大边界、拖动收起、按钮展开、同时隐藏、编辑内容保留、松开和取消、键盘操作、双击重置、窗口缩小再放大及关闭重启后的宽度与隐藏状态记忆。为避免桌面真实鼠标打断CDP拖动，这两项自动化在隐藏的Electron窗口中执行指针操作，按实际窗口尺寸触发resize通知，最后显示窗口取截图。执行结果见测试与验收记录，截图见reports/screenshots中的“三栏拖动”文件。
