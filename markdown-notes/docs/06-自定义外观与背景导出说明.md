# 知页1.3.0：自定义外观与背景导出

日期：2026-10-20。功能来源为用户追加要求：“我还希望可以加入自定义颜色（就是主色调，现在是蓝色）、自定义背景等功能，导出的时候还可以选择带背景导出或者不带背景导出，做完这些之后推送GitHub”。这是内置外观配置，不是原课程P2的插件／主题运行时；原SRS／SDD基线保持不变。

## 使用方式

1. 打开左下角知识库设置，或顶栏“备份与恢复”，切换到“外观”。
2. 主色可以选择六个预设或使用系统颜色选择器。主色应用于按钮、选中状态、链接和焦点。浅色按钮自动使用黑色文字；链接自动采用同色系的较深色，维持可读性。
3. 背景可选默认、纯色或本地图片，背景强度0—100%。下方提供小预览；“应用外观”保存颜色、类别与强度。选择图片后立即保存本机副本，同时应用当前外观草稿；取消选图不提交草稿。
4. “恢复默认外观”恢复原蓝色、默认白灰工作区，并清理当前背景副本。关闭设置但未点应用的颜色／强度修改不保存。
5. 点击笔记右上角“导出PDF”，勾选“带背景导出”或保持不勾选，再点“导出PDF文件”选择位置。每次默认不勾选，避免意外带出私人背景图片。

正文、工具层与底部保存状态保留浅色阅读底层。图片按居中覆盖显示，窗口与A4纸比例不同，裁切可能不同；不承诺像素级截图输出。无背景PDF使用纯白纸面，但保留自定义主色的链接；带背景PDF每页都使用当前已保存的背景与强度，叠加浅色阅读层，并保留页边白色留白。默认背景无自定义图案，勾选也不会增加图片。

Markdown单篇／批量导出仍输出纯Markdown内容，不附带背景文件或CSS；完整资料备份仍按原格式保存业务资料。背景选择适用于PDF，不改变备份／恢复语义。

## 本机保存、图片限制与异常

外观配置位于Electron用户数据目录下 `appearance/appearance.json`，背景副本位于同一目录；与业务资料库 `library` 分开，不包含在完整资料备份、回收站、搜索索引或Git交付包中。跨设备使用相同外观需在新设备重新选择颜色和图片。移走原图不会影响副本；程序更新保留用户数据目录时仍能沿用外观。

只接受PNG／JPEG，原文件不超过8 MiB，单边不超过8192像素且总像素不超过2000万。先校验文件头与尺寸，再用Electron解码并转换为PNG；最长边最多2560像素，转换结果过大时再次缩小，副本上限16 MiB。保存的是普通栅格副本，不接受SVG、远程URL或用户指定的内部文件路径。

主进程原生文件选择器授权读取图片，渲染器只获得已校验副本的数据URL。设置只允许十六进制颜色、固定背景类别和整数强度；不能提交任意CSS、脚本或路径。配置以临时文件再重命名保存，失败不更新内存中的有效设置；图片选择失败保留此前配置。损坏配置回退默认外观并提示，原损坏配置保留到用户明确保存／重置；图片副本后续不可用时回退默认背景，并在外观页提示重新选择。

PDF后台读取已保存外观，等待图片解码与公式字体就绪，再用既有的临时文件发布流程输出。导出失败保留旧目标文件；不加载网络图片。图片副本只用于外观，不开启正文附件功能。

## 实现定位与验证

| 位置 | 职责 |
|---|---|
| `shared/appearance.ts` | 受限配置、颜色对比与背景变量 |
| `appearance-store.ts` | 主进程本机配置、受控图片读取、转换、副本与损坏回退 |
| `renderer/appearance.tsx`、`appearance.css` | 外观设置、预览、颜色与背景应用 |
| `main.ts` | 受信任的appearance接口、PDF背景选项与只读快照 |
| `renderer/print.ts`、`print.css` | 图片准备、每页背景、纯白输出 |

新增2项核心测试：96种颜色组合的按钮／悬停与白底链接对比、非法设置及背景变量；新增2项桌面测试：完整设置流程、自定义颜色输入、原图删除、关闭重开、跨页两种PDF、恢复默认、非法图片与字段拒绝、损坏配置回退及保全。保留公式、安全预览、自动保存、三栏调整、备份恢复和退出回归。

完整实际结果见[测试记录](02-测试与验收记录.md)。PDF另由 `scripts/inspect-appearance-pdf.py` 检查两份实际输出的页数、每页背景像素／纯白像素、中文正文、公式中文、末段、字体嵌入和替换字符；[原始结果](../reports/appearance-pdf-validation.json)与[逐页对比图](../reports/外观导出-对比.png)保留。测试使用合成色块图片，不含个人照片。

界面截图：[外观设置](../reports/screenshots/知页-外观设置.png)、[自定义背景工作区](../reports/screenshots/知页-自定义背景.png)。

开发过程中曾有一项自动化在重启后、界面完成挂载前立即关闭而超时；补充等待界面就绪后重跑通过，未将这次失败记为通过。原生系统颜色选择器的物理鼠标操作、所有图像编码变体及极限背景内存压力没有穷尽验证；历史1.0.0满容量性能不作为1.3.0新外观的实测。

最后一轮旧布局断言曾将319.9998779px与320px的浮点差异判为失败；改为0.05px以内的比较精度后复测，未改抽屉宽度。失败日志与JSON保留于 `reports/desktop-tests-before-precision-fix.*`，不将失败样本改写为通过。
