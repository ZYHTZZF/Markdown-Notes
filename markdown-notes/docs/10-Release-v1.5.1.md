# 知页 v1.5.1 · 新建时直接选模板

- 点击“新建笔记”、空状态新建入口或按Ctrl+N，直接弹出模板选择。
- 空白笔记、课程／会议／阅读内置模板及已有自定义模板集中展示，点击卡片即可创建。
- 取消或Escape关闭不会生成笔记；选定后先保存当前草稿，创建完成自动聚焦编辑器。
- 左侧“笔记模板”继续用于新增、修改和删除模板，数据与备份格式保持不变。

已通过42项核心测试、19项Electron桌面流程、10轮退出诊断及实际Windows成品验证。Windows x64成品解压后运行“知页.exe”，请保留整个目录。源码与测试记录及SHA256校验文件随版本提供。
