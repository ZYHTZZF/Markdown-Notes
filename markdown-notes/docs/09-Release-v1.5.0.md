# 知页 v1.5.0 · 更顺手的知识整理

- **目录大纲**：识别多级标题，点击在写作、分屏、阅读和即时模式跳转，支持重复标题。
- **双向引用自动补全**：输入 `[[` 选择已有笔记；支持键盘和鼠标、中文和特殊字符标题。
- **笔记模板**：课程、会议、阅读内置模板；保存当前正文为自定义模板，编辑、复用与删除。
- **收藏与置顶**：独立收藏入口，普通列表置顶优先，支持收藏中的搜索和标签筛选。
- 本次公开发行同时包含v1.4.0的**即时编辑模式**，可输入 `## ` 直接呈现二级标题；继续保留源码分屏、数学公式、中文PDF和自定义外观。

**备份兼容**：v1.5.0写出格式2完整备份，保存收藏、置顶和自定义模板；仍能读取格式1旧备份。旧版不能恢复格式2，请使用新版恢复。建议升级前保留独立完整备份。外观与窗口布局仍只存本机。

Windows x64成品解压后运行“知页.exe”，请保留整个目录中的资源与DLL。源码与测试记录包包含使用、实现和验证说明；SHA256SUMS.txt可核对附件完整性。

验证：42项核心／集成／容量／安全测试、18项Electron桌面流程、10轮退出诊断及实际Windows成品验证。原全容量性能记录仍为1.0.0历史样本，真实新用户任务、断电和全量输入法人工验证不在本轮已完成范围。
