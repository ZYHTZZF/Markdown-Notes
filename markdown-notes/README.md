# 知页 · 个人 Markdown 笔记与知识管理工具

软件工程课程项目的Windows桌面版，版本1.4.0。采用Electron、React、TypeScript与SQLite，按实验一SRS V1.1和实验二SDD V1.1开发，并按用户追加要求支持数学公式、PDF、自定义外观和即时编辑。

## 直接运行

打开[成品目录](release/知页-win-x64)，双击其中的 **知页.exe**。无需安装Node.js或联网。请保留同目录DLL、资源及许可证文件，不要只复制一个EXE。

个人数据默认存放在Windows用户应用数据目录中的“知页/library”，准确位置可在软件“知识库设置 → 资料库”查看。程序目录与个人资料目录分开，更换程序文件不会自动迁移资料。

## 已实现功能

- Markdown笔记新建、编辑、查看、重命名与安全预览，支持常用标题、列表、任务列表、引用、代码、表格及超链接。
- 停止输入1秒后自动保存，持续输入期间定期保存；分别显示正文持久化与索引状态。Ctrl+N新建、Ctrl+S保存、Ctrl+K搜索。
- 标签新建、修改、删除、多标签关联与交集筛选。全局删除同时清理回收站中的关联。
- 标题、正文、标签及综合字面搜索，NFC与ASCII大小写规则，匹配高亮，每页50条，资料变化后查询失效并刷新。
- `[[笔记名称]]`双向引用、目标跳转、反向链接、出现次数、自引用与失效提示；代码、公式区域及转义标记不产生关系。
- 原子重命名联动，包含自引用；同名新建按当前名称重新绑定。容量超限或业务写入失败整笔拒绝。
- 回收站、恢复改名及永久删除确认；恢复时按当前标题解析，已删除标签不会复活。
- 单篇Markdown正文导出，全部有效笔记ZIP＋元数据清单导出。
- 常用LaTeX数学公式离线预览，支持四种定界符、分式、上下标、积分、求和、矩阵及对齐环境；单篇PDF导出保留中文与公式字体。
- 自定义主色、纯色／本地图片背景、强度调节、本机记忆与恢复默认；PDF可选择带背景或纯白导出。
- 可选“即时”模式：在同一区域直接编辑呈现后的Markdown，输入 `## ` 自动显示为二级标题，原有写作／分屏／阅读继续保留。
- 手动完整备份、恢复前保护备份、正常及故障恢复，摘要／CRC／结构／外键／容量校验，独立资料库代构建与切换。
- 数据库损坏时停止写入并显示恢复入口；原始资料与输入备份保留。单资料库排他写入锁。
- 本机索引重建、版本追平、WAL压力监测和状态反馈；字号、编辑视图偏好与离线帮助。

P2插件／主题运行时按原文档后置；云同步、移动端、多人协作、Markdown导入与附件不在本版范围。数学公式与单篇PDF属于用户本轮明确追加功能，原课程基线保持原样。

## 数学公式与PDF导出

“知识库设置 → 外观”可选择主色、背景颜色／PNG或JPEG图片及强度，点击“应用外观”保存；选图立即保存副本。外观仅存本机，不包含在业务备份中。详细限制和跨页导出规则见[自定义外观说明](docs/06-自定义外观与背景导出说明.md)。

行内使用 `$E=mc^2$` 或 `\(E=mc^2\)`，独立公式使用 `$$…$$` 或 `\[…\]`。多行公式将定界符单独放一行；矩阵与对齐分别使用 `pmatrix`／`bmatrix`、`aligned` 等KaTeX支持的环境，中文说明建议写成 `\text{中文}`。软件不依赖CDN或在线字体，不要求安装LaTeX。

```text
$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$
```

点击笔记右上角“导出PDF”（文件向下箭头图标），选择是否“带背景导出”，再点“导出PDF文件”选择保存位置。默认不带背景。系统先保存当前修改，再将这篇笔记的标题、正文与公式排版为A4文档，嵌入用到的中文、公式字体；PDF文字可选择。Markdown导出按钮继续保留。

代码内的公式标记保持字面；金额中的美元符号可写成 `\$`。不完整定界符保持普通文字，错误公式显示源码提示，原始内容不会丢失。超长公式建议用 `aligned` 手动分行；详细规则与边界见[数学公式与PDF说明](docs/05-数学公式与PDF导出说明.md)。PDF用于阅读分享，不包含标签、回收站等完整元数据，不能用来恢复资料库。

## 即时编辑

点击笔记工具栏“即时”，输入 `## ` 后直接写标题，列表、引用、粗体等随输入呈现。公式和表格点击后修改源码，移开光标恢复显示；Ctrl+单击跳转引用或链接。Ctrl+Z／Ctrl+Y撤销重做，格式工具和原自动保存继续生效。切回分屏可查看完整Markdown。

本模式始终保存Markdown原文，单纯切换不重写正文；模式选择只记在本机，保持既有备份格式兼容。它提供常用语法的同区编辑，复杂排版仍可用源码模式。详细边界见[即时编辑说明](docs/07-即时编辑模式说明.md)。

## 三栏宽度调整

拖动导航与列表、列表与编辑区之间的分隔条可改变宽度；编辑区自动占据剩余空间。双击或聚焦后按Enter恢复该栏默认值，方向键微调。到最窄后继续向左拖并松开可隐藏，顶栏两个按钮可重新展开；松开后自动记忆本机宽度与隐藏状态，缩小窗口会按最小空间约束临时收紧，放大后恢复选择。详情见[三栏宽度调整说明](docs/04-三栏宽度调整说明.md)。

## 使用流程

1. 点击“新建笔记”，在编辑区输入Markdown；点击标题旁铅笔重命名。
2. 点击“添加标签”分类，左侧选择多个标签取交集。
3. 搜索框输入关键词并选择字段范围；点击结果打开当前保存版本。
4. 在普通正文中输入`[[另一篇笔记的标题]]`。等待保存和索引就绪后，在预览或工具条“引用”打开的右侧面板中跳转。
5. 笔记右上角可分别导出Markdown与PDF；“备份与恢复”可以创建完整备份、导出全部Markdown和恢复备份。**Markdown和PDF导出都不能用作完整恢复输入。**

完整备份含回收站、标签及可移植偏好，不含索引缓存、旧备份文件或本机绝对路径。ZIP默认不加密，请自行安排备份频率、保留数量和独立介质副本；软件不自动轮换或删除成功备份。跨设备迁移是在兼容Windows环境手动复制完整备份，再整体恢复，不合并两端资料。

## 从源码运行

开发环境：Node.js 24及npm。依赖版本固定在package-lock.json；首次安装需要网络，安装后的成品运行无需网络。

```text
npm ci
node node_modules/electron/install.js
npm run build
npm start
```

若环境允许npm执行Electron安装脚本，第二步会直接结束而不重复下载。构建将前端资源和后台依赖打包到dist；运行时使用Electron内置Node SQLite，不依赖额外Python、数据库服务器或本机C++编译器。

```text
npm run typecheck     类型检查
npm test              核心、容量、安全、恢复与中断测试
npm run test:e2e      真实Electron桌面流程测试
npm run verify        检查并将验证记录保存至reports
npm run bench         满容量合成资料库性能测试（耗时较长）
npm run package       构建Windows可运行目录
```

测试使用临时合成资料库，不读写日常资料。`ZHIYE_DATA_DIR`可指定独立测试资料目录；未设置时使用正常用户数据目录。测试结束后再清理相应临时目录，运行中的资料库不能手动删除WAL或数据库文件。

## 文件结构

| 位置 | 用途 |
|---|---|
| src/main.ts、src/preload.ts | 桌面宿主、安全协议、原生对话框与受限IPC |
| src/pdf-export.ts、src/print-preload.ts、print.html | 隔离打印窗口、只读文档快照与原子PDF输出 |
| src/shared | 业务类型、字符规则、引用解析、安全Markdown生成 |

| src/backend/indexer.ts | 独立搜索／引用索引工作进程、重建及版本追平 |
| src/backend/archive.ts | 流式备份包、摘要、CRC、结构验证和导出 |
| src/backend/service.ts | 用例编排、任务互斥、本机控制、恢复切换与运行监测 |
| src/renderer | React界面及样式 |
| tests | 单元、集成、安全、容量、进程中断及桌面端测试 |
| reports | 本次实际检查和性能原始记录 |
| docs | 使用／实现对照与验收状态说明 |
| release/知页-win-x64 | 可直接运行的Windows成品 |
